# Benri v1.1.1

Benri v1.1.1 improves appearance consistency and adds a shorter clipboard-retention choice.

## Highlights

- Follow the current macOS light or dark appearance throughout the command palette.
- Use system-adaptive text, selection, border, background, and material colors.
- Retain clipboard history for only the most recent 3 hours when desired.
- Keep pinned clipboard items regardless of the selected retention period.
- Simplify the footer hint to show only `Tab` switching without repeating the active mode.
- Ship a Universal 2 archive for Apple Silicon and Intel Macs.

## Distribution

This self-use archive is ad-hoc signed and is not notarized by Apple. macOS may require you to Control-click the app and choose **Open** the first time. GitHub shows the SHA-256 digest in the release asset metadata; no separate checksum download is required.

## Clipboard privacy

Clipboard history remains a plaintext local cache and is excluded from encrypted `.benribackup` packages. Monitoring requires first-use confirmation and can be paused or cleared at any time.
