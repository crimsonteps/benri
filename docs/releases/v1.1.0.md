# Benri v1.1.0

Benri v1.1.0 focuses on safe long-term use and trustworthy public distribution.

## Highlights

- Create validated `.benribackup` packages from the app or menu bar.
- Restore a backup only after its encrypted vault, key, manifest, and data counts all pass validation.
- Preserve a recovery backup before replacing a healthy vault.
- Export a privacy-safe diagnostic report that excludes record names and content.
- Check for updates manually through the official Releases page without background network activity.
- Complete the Benri bundle identifier and local storage naming transition.
- Improve keyboard navigation, automatic paste reliability, record panels, and glass styling.
- Ship a Universal 2 archive for both Apple Silicon and Intel Macs.

## Distribution

The official archive is Developer ID signed, submitted to Apple for notarization, stapled, and checked with Gatekeeper before publication. GitHub shows the SHA-256 digest in the release asset metadata; no separate checksum download is required.

## Backup security

A `.benribackup` package contains both the encrypted vault and its matching key so it can be restored on another Mac. Store it somewhere private and treat it as sensitive data.
